# Specialized Skills

This directory contains 10 specialized skill definitions that extend Claude Code's capabilities in specific technical domains.

- **Format**: Comprehensive skill definitions with expertise areas, capabilities, and best practices

## 🎯 Available Skills

### 1. **React Component Architect** (3.6KB)
**File**: `react-component-architect.md`

**Expertise Areas**:
- Component API design (compound components, render props, hooks)

- Storybook documentation and design systems

## 🎯 Skill Structure

Each skill definition includes:

### 1. Purpose
Clear mission statement and primary responsibility

### 2. Expertise Areas (10-15 specific domains)
Detailed breakdown of specialized knowledge

### 3. When to Use
Specific scenarios that trigger this skill

### 4. Capabilities (10-15 actions)
Concrete tasks the skill can perform

### 5. Approach (9-11 steps)
Step-by-step methodology for problem-solving

### 6. Tech Stack Focus
Relevant tools, frameworks, and technologies

### 7. Best Practices (15-18 principles)
Key principles to follow for quality outcomes

### 8. Deliverables
Expected outputs and artifacts

## 💡 How to Use Skills

### Conceptual Usage

Skills define specialized expertise that can guide your development:

1. **Reference during planning** - Check which skill applies to your task
2. **Follow the approach** - Use the step-by-step methodology
3. **Apply best practices** - Ensure your work follows the principles
4. **Validate deliverables** - Confirm you've produced the right outputs

### Example Workflow

```
Task: Build a React component library

→ Use "React Component Architect" skill
→ Follow the 11-step approach
→ Apply the 17 best practices
→ Deliver: Reusable components, Storybook stories, TypeScript types, tests
```

### Combining Skills

Many tasks require multiple skills working together:

```
Building a microservice API:
1. "Microservice Expert" - Service architecture
2. "API Designer" - API endpoints and contracts
3. "Database Architect" - Data model
4. "Testing Strategist" - Test strategy
5. "DevOps Engineer" - Deployment pipeline
6. "Security Auditor" - Security review
```
