# SEO Strategy & Keyword Research

Develop a comprehensive SEO strategy and keyword research plan for the website or business specified by the user.

## Instructions

Create a detailed SEO strategy that includes:

### 1. SEO Audit and Baseline
- Current website SEO health assessment
- Technical SEO issues
- Content quality evaluation
- Backlink profile analysis
- Current keyword rankings
- Organic traffic analysis
- Competitor SEO comparison

### 2. SEO Goals and Objectives
- Organic traffic targets
- Keyword ranking goals
- Domain authority improvement
- Conversion rate goals
- Timeline and milestones
- ROI projections

### 3. Keyword Research

#### Primary Keywords:
- High-volume, high-intent keywords
- Commercial intent keywords
- Brand keywords

#### Secondary Keywords:
- Supporting keywords
- Long-tail variations
- Question-based keywords
- "People also ask" opportunities

#### Keyword Analysis:
For each keyword cluster:
- Search volume
- Keyword difficulty
- Current ranking position
- Search intent (informational, navigational, commercial, transactional)
- SERP features present
- Competition level
- Opportunity score

#### Keyword Mapping:
- Keywords by page/URL
- Content gaps to fill
- Cannibalization issues
- Priority order

### 4. Competitive SEO Analysis
- Top organic competitors
- Competitor keyword gaps
- Competitor backlink analysis
- Content gaps and opportunities
- SERP feature dominance
- Competitor strengths and weaknesses

### 5. Technical SEO Strategy
- Site architecture optimization
- URL structure recommendations
- Mobile optimization
- Page speed improvements
- Core Web Vitals optimization
- Crawlability and indexation
- XML sitemap optimization
- Robots.txt configuration
- Schema markup implementation
- HTTPS and security
- Duplicate content issues
- Canonical tag strategy
- Pagination handling
- International SEO (hreflang)

### 6. On-Page SEO Strategy
- Title tag optimization
- Meta description optimization
- Header tag (H1-H6) structure
- Content optimization guidelines
- Keyword placement best practices
- Image optimization (alt text, file names)
- Internal linking strategy
- User experience optimization
- Content-length recommendations
- Multimedia integration

### 7. Content SEO Strategy
- Content types to create (guides, tutorials, comparisons, etc.)
- Topic clusters and pillar pages
- Content depth and quality standards
- E-E-A-T optimization (Experience, Expertise, Authoritativeness, Trust)
- Featured snippet optimization
- "People also ask" targeting
- Video and image SEO
- Content update and refresh schedule

### 8. Local SEO Strategy (if applicable)
- Google Business Profile optimization
- Local keyword targeting
- NAP (Name, Address, Phone) consistency
- Local citations and directories
- Local link building
- Review generation strategy
- Local content creation

### 9. Off-Page SEO and Link Building
- Link building goals
- Target domain authority range
- Link building tactics:
  - Guest posting opportunities
  - Digital PR and outreach
  - Resource page links
  - Broken link building
  - Competitor backlink replication
  - Content partnerships
  - Industry directories
  - HARO (Help a Reporter Out)
  - Unlinked brand mentions
- Outreach templates
- Link quality criteria
- Toxic link audit and disavow

### 10. SERP Feature Optimization
Strategy for capturing:
- Featured snippets
- People also ask boxes
- Image pack
- Video results
- Local pack
- Knowledge panel
- Site links
- Review stars

### 11. SEO Content Calendar
- Priority content to create
- Content optimization schedule
- Publishing frequency
- Seasonal content opportunities
- Trend-jacking opportunities

### 12. Conversion Rate Optimization (CRO)
- Landing page optimization
- Call-to-action improvements
- User journey optimization
- A/B testing plan
- Conversion tracking setup

### 13. SEO Tools and Technology
- Keyword research tools
- Rank tracking tools
- Analytics and reporting tools
- Technical SEO audit tools
- Backlink analysis tools
- Content optimization tools

### 14. Metrics and KPIs
- Organic traffic growth
- Keyword rankings (by tier)
- Domain authority/rating
- Page authority
- Backlink metrics (quantity, quality, referring domains)
- Organic conversion rate
- Pages indexed
- Core Web Vitals scores
- Click-through rate (CTR)
- Bounce rate and dwell time

### 15. Reporting and Analysis
- Reporting frequency
- Key dashboards
- Stakeholder reports
- Performance analysis methodology
- Algorithm update monitoring

### 16. Implementation Roadmap

#### Quick Wins (0-30 days):
- Immediate technical fixes
- Title and meta description updates
- Quick content optimizations

#### Short-term (1-3 months):
- Technical SEO improvements
- On-page optimization
- Initial content creation
- Link building launch

#### Medium-term (3-6 months):
- Content hub development
- Link building momentum
- Authority building

#### Long-term (6-12 months):
- Domain authority growth
- Comprehensive content library
- Industry leadership positioning

### 17. Risk Management
- Algorithm update preparedness
- Penalty recovery plan
- Competitor response strategies
- Traffic dependency mitigation

## Output Format

Deliver:
1. Executive summary with key recommendations
2. Comprehensive keyword research table (50-100 keywords)
3. Prioritized technical SEO checklist
4. Content creation roadmap
5. Link building action plan
6. 90-day implementation timeline
7. Metrics dashboard description
8. Monthly reporting template outline

Organize by priority: High-impact quick wins → Strategic long-term initiatives

Ask clarifying questions about the website, industry, current SEO efforts, resources, and goals before developing the strategy.
