# Email Marketing Campaign Creator

Create a comprehensive email marketing campaign with sequences, copy, and strategy for the product or objective specified by the user.

## Instructions

Develop a complete email marketing campaign including:

### 1. Campaign Overview
- Campaign name and objective
- Target audience and segmentation
- Campaign duration
- Key messages
- Success metrics
- Budget considerations

### 2. Campaign Strategy
- Campaign type (nurture, promotional, onboarding, re-engagement, etc.)
- Email sequence structure
- Timing and cadence
- Personalization strategy
- A/B testing plan
- Integration with other channels

### 3. Audience Segmentation
- Segment definitions
- Segment-specific messaging
- Dynamic content strategy
- Behavioral triggers
- Personalization tokens

### 4. Email Sequence Architecture

Design a multi-email sequence (typically 5-8 emails) with:
- Sequence flow and logic
- Email timing (day 0, day 2, day 5, etc.)
- Trigger conditions
- Exit criteria
- Branch logic for different behaviors

### 5. Individual Email Templates

For each email in the sequence, provide:

#### Email Header:
- Email number in sequence
- Internal name
- Send timing
- Segment/audience

#### Subject Lines:
- Primary subject line
- 2-3 A/B test variants
- Emoji usage (if appropriate)
- Personalization elements
- Character count (aim for 40-50)

#### Preview Text:
- Compelling preview text (50-100 characters)
- Complements subject line
- Provides additional context

#### Email Body:
- Opening hook
- Body copy (short paragraphs, scannable)
- Value proposition
- Social proof or testimonials (where applicable)
- Call-to-action (CTA)
- P.S. line (if appropriate)
- Footer elements

#### Design and Layout:
- Header design description
- Hero image/graphic suggestion
- Layout structure (single column, etc.)
- Brand elements
- Mobile optimization considerations

#### Call-to-Action (CTA):
- CTA copy
- CTA button design
- Primary and secondary CTAs
- Link destination

### 6. Email Copywriting Best Practices Applied
- Conversational tone
- Benefit-focused messaging
- Urgency and scarcity (where appropriate)
- Storytelling elements
- Addressing objections
- Personalization
- Clarity and brevity

### 7. Sample Email Sequence Structure

#### Example for Welcome/Onboarding Series:

**Email 1 (Day 0):** Welcome
- Thank you for signing up
- Set expectations
- First value delivery
- Encourage quick win

**Email 2 (Day 2):** Education
- Key feature highlights
- How to get started
- Resources and tutorials
- Success stories

**Email 3 (Day 5):** Value Demonstration
- Use case examples
- Customer testimonials
- Deeper feature education
- Remove friction

**Email 4 (Day 8):** Social Proof
- Case studies
- Customer reviews
- Industry recognition
- Community engagement

**Email 5 (Day 12):** Conversion Push
- Special offer or incentive
- Limited-time opportunity
- Clear value proposition
- Strong CTA

**Email 6 (Day 16):** Last Chance
- Final reminder
- Urgency messaging
- Overcome objections
- Make it easy to convert

**Email 7 (Day 21):** Alternative Path
- Different angle or offer
- Request feedback
- Provide alternative value
- Keep relationship warm

### 8. Technical Setup
- Email service provider (ESP) recommendations
- List management
- Automation workflow
- Trigger setup
- Tagging and tracking
- Deliverability best practices

### 9. Design Specifications
- Template design requirements
- Brand guidelines integration
- Image specifications
- Button styling
- Font and typography
- Color scheme
- Mobile responsive requirements
- Dark mode considerations

### 10. Personalization Elements
- Merge tags to use (first name, company, etc.)
- Dynamic content blocks
- Behavioral data usage
- Segment-specific variations
- Geo-targeting

### 11. Testing Strategy
- A/B test elements:
  - Subject lines
  - Send times
  - From name
  - CTA copy and design
  - Email length
  - Content variations
- Sample size requirements
- Statistical significance threshold
- Testing timeline

### 12. Metrics and Analytics
- Open rate targets
- Click-through rate (CTR) goals
- Conversion rate objectives
- Unsubscribe rate monitoring
- Revenue per email
- List growth rate
- Engagement over time
- Deliverability metrics (bounce rate, spam complaints)

### 13. Deliverability Optimization
- Sender reputation management
- Authentication (SPF, DKIM, DMARC)
- List hygiene practices
- Subject line spam trigger avoidance
- Text-to-image ratio
- Link best practices
- Unsubscribe placement

### 14. Compliance and Legal
- CAN-SPAM compliance
- GDPR compliance
- CASL compliance (Canadian)
- Unsubscribe mechanism
- Privacy policy links
- Preference center
- Data handling

### 15. Follow-up Actions
- Post-campaign analysis
- Winner implementation from A/B tests
- Segment performance review
- Content refreshment schedule
- Re-engagement campaigns
- List cleanup

### 16. Timeline and Project Plan
- Copy writing deadline
- Design deadline
- Review and approval
- Technical setup
- Testing period
- Launch date
- Campaign end date
- Analysis and reporting

## Output Format

Provide:
1. Campaign strategy overview
2. Complete email sequence map (visual description)
3. Full copy for each email (5-8 emails)
4. Subject line variations
5. Design specifications and layout descriptions
6. Testing and optimization plan
7. Metrics dashboard template
8. Implementation checklist

Format each email with:
- Clear headers
- Scannable structure
- CTA emphasis
- Character counts where relevant

Ask clarifying questions about the product, audience, campaign goals, and existing email marketing infrastructure before creating the campaign.
