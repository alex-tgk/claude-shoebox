# High-Converting Landing Page Copywriter

Write compelling, conversion-optimized landing page copy for the product, service, or campaign specified by the user.

## Instructions

Create comprehensive landing page copy that includes:

### 1. Landing Page Strategy
- Page objective and primary conversion goal
- Target audience and stage in buyer journey
- Key message and value proposition
- Differentiation strategy
- Urgency and scarcity elements

### 2. Above the Fold

#### Headline:
- Main headline (clear, benefit-driven, attention-grabbing)
- Alternative headline variations for A/B testing (3-5 options)
- Character count and clarity check

#### Subheadline:
- Supporting subheadline (expands on headline, adds specificity)
- Alternative variations
- Length: 1-2 sentences

#### Hero Section:
- Opening hook or context
- Primary value proposition
- Trust indicator or social proof element
- Hero image or video description

#### Primary CTA:
- CTA button copy (action-oriented, specific)
- CTA button variations for testing
- Secondary CTA (if applicable)
- CTA design notes (color, size, placement)

### 3. Social Proof Section
- Customer testimonials (2-3 with names, titles, photos)
- Customer logos (10-15 recognizable brands)
- Statistics and numbers (users, satisfaction rate, etc.)
- Awards and recognition
- Trust badges and security certifications
- Media mentions

### 4. Problem/Pain Points Section
- "Are you struggling with..." or similar framing
- 3-5 specific pain points your audience faces
- Empathetic copy that shows understanding
- Emotional connection
- The cost of not solving the problem

### 5. Solution Overview
- "Introducing [Product Name]" section
- How it works (high-level overview)
- Why it's different
- Core promise and benefit
- Bridge from problem to solution

### 6. Features and Benefits Section

For each key feature (3-5 features):
- Feature name/title
- Feature description
- Benefit translation (what it means for the user)
- Icon or visual description
- Supporting details

Use the "Feature → Benefit" framework:
- Feature: What it is
- Benefit: What it does for the user
- Outcome: The end result or transformation

### 7. How It Works
- Step-by-step process (3-4 steps)
- Each step with:
  - Step number and title
  - Description (2-3 sentences)
  - Visual element description
- Emphasize simplicity and ease

### 8. Product Demo or Screenshot Section
- Product interface descriptions
- Key features highlighted
- Use case demonstration
- Before and after scenarios
- Interactive element descriptions

### 9. Use Cases or Applications
- "Perfect for..." section
- 3-5 specific use cases
- Real-world applications
- Industry-specific examples
- Role-specific benefits

### 10. Comparison Section
- "Why Choose Us" or "How We Compare"
- Comparison table (You vs. Competitors/Alternatives)
- Key differentiators highlighted
- Unique advantages
- What makes you better/different

### 11. Pricing Section (if applicable)
- Pricing headline
- Pricing tiers with features
- Value emphasis
- Price anchoring
- Money-back guarantee
- "No credit card required" or similar
- FAQ about pricing

### 12. Testimonials and Case Studies
- Detailed customer testimonials (3-5)
- Case study snapshots
- Video testimonial descriptions
- Results and outcomes
- Specific metrics and improvements
- Diverse customer representations

### 13. FAQ Section
- 6-10 common questions and answers
- Objection handling
- Technical questions
- Pricing and billing questions
- Security and privacy
- Support and onboarding
- Competitive comparisons

### 14. Final CTA Section
- Compelling headline
- Reinforced value proposition
- Urgency element
- Risk reversal (guarantee, free trial, etc.)
- Primary CTA button
- Trust reinforcement
- "What happens next" clarity

### 15. Footer Elements
- Navigation links
- Contact information
- Social proof elements
- Privacy policy and terms links
- Security badges
- Alternative CTAs

### 16. Trust and Credibility Elements Throughout
- Security badges (SSL, encryption, compliance)
- Privacy assurance
- Money-back guarantee
- Free trial or demo
- No credit card required
- Customer support availability
- Data protection compliance (GDPR, etc.)

### 17. Urgency and Scarcity Elements
- Limited-time offers
- Countdown timers (description)
- Stock/availability indicators
- Exclusive bonuses
- Early adopter benefits

### 18. Microcopy
- Form field labels and placeholder text
- Error messages
- Success messages
- Helper text and tooltips
- Navigation elements
- Button hover states

### 19. Mobile Optimization Notes
- Mobile headline variations (shorter)
- Mobile CTA placement
- Mobile-specific content ordering
- Thumb-friendly button sizes
- Reduced cognitive load for mobile

### 20. SEO Optimization
- Title tag
- Meta description
- Header tag structure (H1, H2, H3)
- Primary keyword integration
- Alt text for images
- Schema markup recommendations

### 21. Conversion Optimization Elements
- Clear value hierarchy
- Visual flow guidance
- White space utilization
- Color psychology application
- Directional cues (arrows, eye gaze, etc.)
- Progressive disclosure
- Exit intent pop-up copy

### 22. A/B Testing Recommendations
- Elements to test:
  - Headline variations
  - CTA button copy and color
  - Hero image vs. video
  - Long-form vs. short-form
  - Social proof placement
  - Pricing display methods
  - Form length

### 23. Psychological Triggers Applied
- Reciprocity
- Social proof
- Authority
- Scarcity
- Consistency
- Liking
- Loss aversion
- FOMO (fear of missing out)

## Output Format

Provide:
1. Complete landing page copy from top to bottom
2. Section-by-section breakdown with headers
3. Multiple headline and CTA variations
4. Design and layout notes
5. Visual hierarchy recommendations
6. Conversion optimization notes
7. A/B testing priorities
8. Word count by section

Format the copy with:
- Clear section headers
- Proper formatting (bold, italics, lists)
- CTA callouts
- Design notes in [brackets]
- Alternative copy in {curly braces}
- Character counts where relevant

Create two versions:
1. Long-form (5000+ words) - comprehensive, detail-rich
2. Short-form (1000-1500 words) - concise, focused

Ask clarifying questions about the product, target audience, unique selling propositions, pricing, and any existing copy or brand guidelines before writing.
