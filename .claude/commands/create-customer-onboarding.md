# Customer Onboarding Flow Creator

Create a complete customer onboarding system with welcome email sequence, in-app tour, getting started checklist, tutorials, success metrics, and activation tracking for the product or service specified by the user.

## Instructions

Build a comprehensive onboarding experience including:

### 1. Onboarding Strategy

#### Goals:
- Reduce time-to-first-value
- Increase product activation rate
- Decrease early churn
- Drive feature adoption
- Create product champions

#### Success Metrics (HEART Framework):

**Happiness:**
- NPS score after onboarding
- Customer satisfaction (CSAT)
- Support ticket volume

**Engagement:**
- Daily/weekly active users
- Feature usage rate
- Time spent in product

**Adoption:**
- % of users who complete onboarding
- Time to complete onboarding
- Feature activation rates

**Retention:**
- 7-day retention
- 30-day retention
- Churn rate in first 90 days

**Task Success:**
- Completion of key actions
- Milestones achieved
- Goals accomplished

#### Activation Milestones:

#### Checklist Logic:

```javascript
// Track checklist progress
const checklistItems = [
  {
    id: 'account_created',
    title: 'Create your account',
    autoComplete: true, // Automatically completed on signup
    weight: 1
  },
  {
    id: 'profile_completed',
    title: 'Complete your profile',
    checkFunction: () => user.profile_complete === true,
    ctaAction: () => navigateTo('/profile'),
    weight: 1
  },
  {
    id: 'first_project',
    title: 'Create your first project',
    checkFunction: () => user.projects_count > 0,
    ctaAction: () => openModal('createProject'),
    weight: 2
  },
  {
    id: 'team_invited',
    title: 'Invite your team',
    checkFunction: () => user.invites_sent > 0,
    ctaAction: () => openModal('inviteTeam'),
    weight: 1,
    optional: true
  },
  {
    id: 'integration_connected',
    title: 'Connect integration',
    checkFunction: () => user.integrations_count > 0,
    ctaAction: () => navigateTo('/integrations'),
    weight: 1,
    optional: true
  }
];

// Calculate progress
function calculateProgress() {
  const totalWeight = checklistItems.reduce((sum, item) => sum + item.weight, 0);
  const completedWeight = checklistItems
    .filter(item => item.checkFunction())
    .reduce((sum, item) => sum + item.weight, 0);

  return (completedWeight / totalWeight) * 100;
}

// Award completion bonus
async function checkCompletionReward() {
  const allCompleted = checklistItems.every(item =>
    item.optional || item.checkFunction()
  );

  if (allCompleted && !user.onboarding_reward_claimed) {
    await awardCompletionBonus(user.id);
    showCelebration('onboarding-complete');
    user.onboarding_reward_claimed = true;
  }
}
```

// Check and celebrate milestones
async function checkMilestones(userId, event) {
  for (const [key, milestone] of Object.entries(milestones)) {
    if (eval(milestone.trigger) && !user.milestones_achieved.includes(key)) {
      await celebrateMilestone(userId, milestone);
      await trackMilestone(userId, key);

      if (milestone.reward) {
        await awardReward(userId, milestone.reward);
      }
    }
  }
}

### 7. Personalized Recommendations

#### Recommendation Engine:

```javascript
// Generate personalized next steps
async function getPersonalizedRecommendations(userId) {
  const user = await getUser(userId);
  const behavior = await getUserBehavior(userId);
  const recommendations = [];

  // Based on role/industry
  if (user.role === 'marketer') {
    recommendations.push({
      type: 'feature',
      title: 'Try the Campaign Builder',
      reason: 'Perfect for marketers like you',
      cta: 'Start Campaign',
      url: '/campaigns/new'
    });
  }

  // Based on incomplete actions
  if (behavior.started_project && !behavior.completed_project) {
    recommendations.push({
      type: 'completion',
      title: 'Finish Your Project',
      reason: 'You started this yesterday',
      cta: 'Continue',
      url: `/projects/${behavior.last_project_id}`
    });
  }

  // Based on similar users
  const similarUsers = await findSimilarUsers(userId);
  const popularFeature = getMostUsedFeature(similarUsers);

  if (!behavior.used_features.includes(popularFeature)) {
    recommendations.push({
      type: 'discovery',
      title: `Try ${popularFeature}`,
      reason: 'Users like you love this feature',
      cta: 'Learn More',
      url: `/features/${popularFeature}`
    });
  }

  // Based on time since signup
  if (daysSince(user.created_at) >= 7 && !user.invited_team) {
    recommendations.push({
      type: 'collaboration',
      title: 'Invite Your Team',
      reason: 'Collaboration unlocks more value',
      cta: 'Send Invites',
      url: '/team/invite'
    });
  }

  return recommendations;
}
```
